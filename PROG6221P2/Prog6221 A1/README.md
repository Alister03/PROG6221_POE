A console-based chatbot built in C# that teaches users about cybersecurity fundamentals — password safety, phishing, and safe browsing.
Voice greeting — a recorded WAV message plays when the app launches
ASCII art logo — cybersecurity-themed title screen on startup
Basic response system — answers questions on passwords, phishing, and safe browsing
Personalised interaction — greets the user by name and uses it in responses
Input validation — handles empty and unrecognisable input.
Enhanced console UI — coloured text, dividers, and a typing effect
